# Снежная Долина — лендинг

Вёрстка кейса по макету Figma (кадр `v1`): статичный HTML/CSS/JS без сборки.

- Hero — фоновое видео с зерном и рваным снежным краем.
- «Что входит в организацию» — ховер на плитке накрывает фото тонированным стеклом с блюром.
- «Туры и программы» — ховер на строке меняет фон секции и показывает кнопку; на тач-устройствах активна строка в центре экрана.
- Финал — вырезанный лыжник с параллаксом от курсора и скролла.
- Адаптив до 375 px, бургер-меню, `prefers-reduced-motion`.

## Запуск локально

```bash
python -m http.server 8000
```

## Публикация

GitHub → Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
